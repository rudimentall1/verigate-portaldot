Evidence boundary: a saved transaction record is not a fresh RPC confirmation. If the node has pruned a historical receipt, this Explorer says so instead of fabricating a successful live lookup. The index stores EVM transactions/logs and finalized Substrate events only for the ranges it can read. Registered EVM contract logs can be decoded with a supplied Solidity ABI. Complete native-account mapping, token-holder rankings, and NFT ownership still require runtime-specific state reconstruction.
